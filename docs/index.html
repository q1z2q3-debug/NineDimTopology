摘要

把每味药抽象为九维药效向量，把方剂配伍抽象为向量空间中的耦合拓扑。项目给出 33 味药、12 首经典方剂的向量计算、拓扑识别与逆向推导，并明确这是理论研究工具，不是临床建议。

核心结构

  • 向量合成：V_j = Σ(w_i·v_ij) + Σ(κ_ik·w_i·w_k·(v_ij⊗v_kj))。
  • Kotlin Multiplatform 核心库 + Android Jetpack Compose 应用。
