# 九维耦合拓扑框架 / Nine-Dimensional Coupling Topology

> 一种用于描述中医方剂配伍结构的数学语言 — 将每味药物抽象为九维药效向量，将方剂配伍抽象为向量空间中的耦合拓扑结构。

## 项目简介

九维耦合拓扑框架是一套将中医方剂配伍理论进行数学化建模的研究工具。它通过**九维药效向量**和**十种耦合拓扑类型**，为经典方剂的配伍结构提供可计算、可验证、可逆向推导的形式化描述。

## 核心概念

### 九维药效向量

| 维度 | 名称 | 正向 | 负向 |
|------|------|------|------|
| D1 | 容纳 | 补益滋养 | 泻下耗散 |
| D2 | 温度 | 温热 | 寒凉 |
| D3 | 润燥 | 生津 | 燥湿 |
| D4 | 表达 | 发散宣通 | 内敛收敛 |
| D5 | 固化 | 收敛固涩 | 消散破结 |
| D6 | 结构 | 归经定位 | — |
| D7 | 运动 | 升浮向外 | 沉降向内 |
| D8 | 调和 | 信息整合 | — |
| D9 | 节律 | 周期调节 | — |

### 十种耦合拓扑类型

1. **偏转型**（左金丸）— 单一向量被引导偏转
2. **回路型**（交泰丸）— 双向振荡平衡
3. **三角矢量型**（四逆散）— 三向量合成新方向
4. **分层协同型**（黄连阿胶汤）— 垂直层级组织
5. **并置协同型**（柴胡桂枝汤）— 水平模块并列
6. **环形耦合型**（四君子汤）— 首尾相接正向增益循环
7. **三维对抗型**（六味地黄丸）— 补泻矢量动态张力平衡
8. **星型耦合型**（炙甘草汤）— 中心节点调节多方向张力
9. **时序耦合型**（大承气汤）— 时间矢量接力
10. **桥接型**（小青龙汤·细辛）— 单节点跨层通道

### 向量合成公式

```
V_j = Σ(w_i × v_ij) + Σ(κ_ik × w_i × w_k × (v_ij ⊗ v_kj))
```

**验证示例**：麻黄汤中麻黄+桂枝相须（κ=1.6），使 D7 维度从 12.3 放大至 33.8，效应放大 2.7 倍。

## 功能模块

- **向量计算器**：选择药物、设置剂量、实时计算合成向量
- **方剂分析**：12首经典方剂的耦合拓扑结构解析
- **逆向推导**：从病机向量反推所需拓扑和候选方剂
- **体质辨识**：九种体质基底向量建模与调理方向
